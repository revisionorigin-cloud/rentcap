# RENTCAP — 임대주택 언더라이팅

**기관투자자의 오피스텔 매입 검토 도구.** 국토교통부 실거래가와 한국은행 금리를 실시간으로 불러와 3단계(시장 확인 → 수익률 계산 → 매입가·한계선 확인)로 검토합니다. 가정은 공공데이터로 채우고, 각 가정이 시장의 상위 몇 %에 서 있는지 보여줍니다.

2026 재직자 AI·D 30+ 집중캠프 · R.E.VIBE 트랙 1 최종 미션(옵션 B — 부동산 Finance 자유 주제 · 외부 API 활용) · 10조

## 무엇이 다른가

상업용 부동산 수익성 계산기는 이미 좋은 것이 있습니다. 그러나 매입가·임대료·전환율·성장률을 **전부 사람이 입력**합니다.
매수 측 실무자가 매도자의 IM을 받아 들고 가장 먼저 하는 일은 "이 가정이 시장 대비 공격적인가"를 따지는 것인데, 계산기는 그 질문에 답하지 않습니다.

임대주택은 이 빈자리를 메울 수 있는 유일한 섹터입니다. 오피스 임대료는 공개되지 않지만 **주거 임대료는 국토교통부 실거래가에 전부 있기** 때문입니다.

| | 일반 CRE 계산기 | RENTCAP |
|---|---|---|
| 임대료·매입가 | 사용자 입력 | 실거래가 중앙값으로 채움 (표본 수·출처 표시) |
| 전월세전환율 | 없음 또는 고정값 | 같은 단지·같은 타입의 전세·월세 쌍에서 역산 |
| 임대료 성장률 | 사용자 입력 | 동일 단지 신규 월세 전년비 |
| 금리 | 사용자 입력 | 한국은행 ECOS 실시간 (기준금리·CD·국고채·회사채) |
| 가정 검증 | 없음 | 가정마다 시장 백분위 · 공격적/중립/보수적 판정 |
| 한국 고유 구조 | 보증금 승계 정도 | 보증금×LTV 민감도, 신규−갱신 임대료 격차, 갱신 5% 상한 실측, 법정 전환율 상한 |
| 모르는 것 | 기본값으로 채움 | "자료 없음"으로 비움 (공실률·운영비) |

## 화면 구성

1. **시장** — 시군구·전용면적 구간을 고르면 전환율, 환산월세, 매매 단가, 총수익률, 신규−갱신 격차, 동일 단지 전년비, 갱신 인상률 분포를 계산합니다. 단지를 고르면 타입별 임대·매매와 계약 분포가 나옵니다.
2. **언더라이팅** — 시장값으로 채운 입력에서 Levered/Unlevered IRR, Equity Multiple, CoC, DSCR, 진입 Cap, Debt Yield, 손익분기 입주율을 계산합니다. 입력값은 서버로 가지 않습니다.
3. **한계선과 민감도** — 손익분기를 둘로 나눕니다: ① 자기자본 원금 보전선 ② 대주 상환 한계선. 목표 IRR 기준 최대 매입 단가, DSCR 1.2x 금리를 역산하고, Exit Cap×성장률 · 가산금리×공실률 · 보증금×LTV 세 장의 민감도 표를 냅니다.
4. **검증과 출처** — 데이터 계보(건수·제외 기준·조회일), 산식, 실시간 모델 검증(PASS/FAIL), 법정 기준 조문, 확인하지 못한 것, 보안.

## 외부 API

| API | 용도 | 키 |
|---|---|---|
| 공공데이터포털 · 국토교통부 오피스텔 **전월세** 실거래가 (`RTMSDataSvcOffiRent`) | 임대료 · 보증금 · 계약구분(신규/갱신) · 갱신요구권 · 종전 임대료 | `DATA_GO_KR_KEY` |
| 공공데이터포털 · 국토교통부 오피스텔 **매매** 실거래가 (`RTMSDataSvcOffiTrade`) | 매매가 · 해제 여부 | `DATA_GO_KR_KEY` |
| 한국은행 **ECOS** (`722Y001` 기준금리 · `817Y002` 시장금리) | 대출 기준금리, 법정 전환율 상한, 금리 가정 검증 | `ECOS_API_KEY` (없으면 한국은행 공개 시험키) |

- 공공데이터포털 키가 있으면 **전국 256개 시군구**를 최근 24개월로 실시간 조회합니다.
- 키가 없으면 같은 기관(국토교통부 실거래가 공개시스템)의 공개 CSV로 만든 **스냅샷**(서울 마포·영등포·강남, 2024-09-22 ~ 2026-09-21, 임대 41,903건 · 매매 6,090건)으로 동작하고, 화면에 스냅샷임을 표시합니다. 합성 데이터는 쓰지 않습니다.
- 시군구 코드는 실거래가 공개시스템의 현행 목록(2026년 행정구역 개편 반영)을 씁니다.

### 앱 규칙 (수업 실습 B와 동일)

- 인증키는 `.env.local`과 Vercel 환경변수에만 둡니다. 서버 코드에서만 읽고 `NEXT_PUBLIC_` 접두사를 쓰지 않습니다.
- 외부 API 응답은 서버에서 하루 캐시합니다 (`fetch` `revalidate: 86400`).
- `vercel.json` 서울 리전(`icn1`).

## 핵심 산식

- 전환율 r = 월세×12 ÷ (같은 단지·타입 전세 보증금 중앙값 − 월세 보증금) 의 지역 중앙값
- 환산월세 = (월세 + 보증금×r÷12) ÷ 전용평
- 총수익률 = 같은 단지·같은 타입에서 세대당 환산월세×12 ÷ 매매가 (거래량 가중), 지역값은 단지 중앙값
- Cap = NOI ÷ (가격 − 보증금), 매각가 = 차년도 NOI ÷ Exit Cap + 보증금
- 자기자본 = 매입가 + 취득부대비 − 대출 − 승계 보증금

자세한 제외 기준·법정 근거·한계는 앱의 「04 검증과 출처」에 있습니다.
